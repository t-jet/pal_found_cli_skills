# v2.media_sets.MediaSet.abort


API v2; release stage: Public Beta. Check enrollment enablement and resource access before live execution.

## Purpose and parameter meaning

Aborts an open transaction. Items uploaded to the media set during this transaction will be deleted.

With a configured `foundry_sdk.v2.FoundryClient` named `client`, call `client.media_sets.MediaSet.abort`.
